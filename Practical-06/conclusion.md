## Conclusion

The Chain Matrix Multiplication problem was successfully implemented using the **Dynamic Programming** approach in C language. The program finds the optimal order of multiplying a sequence of matrices with the minimum number of scalar multiplications.

The Dynamic Programming approach avoids repeated calculations by storing the results of previously solved subproblems. The time complexity of the algorithm is **O(n³)** and the space complexity is **O(n²)**.

Thus, Dynamic Programming provides an efficient solution for optimizing the order of matrix multiplication.
